# Spyglass for OpenClaw

Research brands, creators, Meta ads, Instagram posts, and TikTok videos with Spyglass.

This repository contains the standalone skill. Read [SKILL.md](SKILL.md) for setup and usage. Requires Node.js 22+ and a Spyglass API key with credits. Configure SPYGLASS_API_KEY through your host secret settings.

ClawHub publication is managed separately; source availability does not imply marketplace approval.

Run the mocked request tests with `node --test tests/*.test.mjs`. No production credits are used.
